# Security Policy

## Reporting Security Issues

The Konveyor maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/konveyor/operator/security/advisories/new) form.

For more details, see the [Konveyor security policy](https://github.com/konveyor/operator/blob/main/SECURITY.md).
